# Niño Joaquin Lagasca — e-Portfolio

A static, responsive dark luxury editorial portfolio.

## Files
- `index.html` — page structure and portfolio content
- `styles.css` — visual design and responsive layouts
- `script.js` — navigation, section highlighting, reveals, and image lightbox
- `assets/` — supplied profile, project images, and presentation video

## Run locally
Open `index.html` in a browser. For the most reliable local video playback, use a simple local static server.

## GitHub Pages
Upload the contents of this folder to your repository (keep `assets/` beside the three code files), then enable GitHub Pages for the branch and folder you use.

All project details are based on the information and media supplied. Add any missing certificates, documentation links, and additional artifacts when ready.
