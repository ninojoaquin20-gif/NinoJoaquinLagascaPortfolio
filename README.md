# Niño Joaquin Lagasca — e-Portfolio

A static, responsive dark luxury editorial portfolio.

## Files
- `index.html` — page structure and content
- `styles.css` — design and responsive layouts
- `script.js` — navigation highlighting, reveals, and image lightbox
- `assets/` — images, certificate, project PDFs, and presentation video

## Run locally
Open `index.html` in a browser. For the most reliable video playback, use a simple local static server.

## Publish on GitHub Pages
1. Unzip this folder, then drag **everything inside it** (`index.html`, `styles.css`, `script.js`, `README.md`, and the `assets` folder) into your repository's "Add file → Upload files" page, so `index.html` sits at the top level of the repo.
2. Commit the upload.
3. Go to Settings → Pages, choose the branch (usually `main`) and the `/ (root)` folder, and save.
